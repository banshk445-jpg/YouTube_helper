# 유튜브 AI 도우미 (YouTube Helper)

부모님이나 어르신들이 유튜브를 쓰다가 "이 버튼이 뭔지 모르겠다"고 답답해하실 때를 위해 만든 크롬 확장 프로그램입니다.

이 확장 프로그램을 설치하면 AI가 화면 위에서 지금 눌러야 할 버튼을 직접 가리켜주기 때문에, 복잡한 설명 없이도 누구나 유튜브를 쉽게 사용할 수 있습니다.

## 누구를 위한 프로그램인가요?

유튜브가 낯선 어르신, 처음 스마트폰/컴퓨터를 다루는 초보 사용자를 위해 만들었습니다.

## 핵심 기능

- 화면 위에서 AI가 다음에 눌러야 할 버튼을 직접 표시
- 유튜브 화면을 그대로 사용하면서, 헷갈리는 부분만 옆에서 도와주는 방식

## 어떻게 만들었나요?

- 크롬 확장 프로그램(Chrome Extension) 구조로 설계
- 유튜브 페이지에 실시간으로 개입하는 스크립트 작성 (`content.js`, `content.css`)
- 서버(Cloudflare Workers)와 연동하여 AI 응답 처리
- 사용자 설정을 위한 팝업 화면 구성 (`popup`)

## 폴더 구성

| 폴더/파일 | 설명 |
|---|---|
| `popup/` | 확장 프로그램 클릭 시 뜨는 설정 화면 |
| `content.js` / `content.css` | 유튜브 페이지 위에 표시되는 안내 UI |
| `background.js` | 확장 프로그램 백그라운드 동작 처리 |
| `manifest.json` | 크롬 확장 프로그램 기본 설정 파일 |
| `icons/` | 확장 프로그램 아이콘 |
| `docs/` | 문서 |

## 만든 이유

유튜브는 익숙한 사람에게는 쉽지만, 처음 접하는 어르신에게는 버튼 하나하나가 낯설고 어렵습니다. 옆에서 매번 알려드릴 수 없으니, AI가 대신 화면에서 안내해주면 어떨까 하는 생각에서 시작한 개인 프로젝트입니다.
